Run on 2026-10-17 against commit `2dd03d4` plus this doc. Setup: production client build
served by the server (`TIMINGS=fast ALLOW_SOLO=1`, and once with prod timings +
`ALLOW_SHORT_DUBBING=1` to see the results screen properly), `CLIPS_DIR=.cache/dev-clips`
(VP9/Opus test patterns). Browsers: Playwright **Chromium 1248** (headless shell and the

Firefox prefs `media.navigator.streams.fake=true`, `media.navigator.permission.disabled=true`.

390×844 and the other at 1280×800.
